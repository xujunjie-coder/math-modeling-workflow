# 视觉质量自检与审核通关清单 (Visual Review & QA Checklist)

所有生成的科研插图，在嵌入最终论文或提交前，必须经过本清单的**“12 项通关审计”**。只有全部勾选通过，方可放行。

---

## 一、Visual QA 12 项通关审计清单

```markdown
[ ] 1. 【论点匹配】图表直接证明论文中的哪项核心结论？结论是否与正文陈述 100% 吻合？
[ ] 2. 【数据真实】关键点数值（如峰值收率 50.31%、半衰期 101.4 min）是否与计算代码产出严格一致？
[ ] 3. 【样本透明】是否存在隐藏底层离散度的问题？小样本是否呈现了真实散点？
[ ] 4. 【坐标零点】柱状图是否严格从 0 起算？折线图截断是否有醒目断轴标示？
[ ] 5. 【物理量纲】所有 X、Y 轴及 Colorbar 是否均标注了清晰的中文名称与法定计量单位？
[ ] 6. 【多图对齐】复合子图 (a)、(b) 之间相同维度的坐标范围与网格比例是否对齐？
[ ] 7. 【统一色系】是否严格遵循本工作区统一科研色板？（发散用红蓝 cm_diverging，离散用 SCI_PALETTE）
[ ] 8. 【图例避让】图例是否安放在空白区或右侧外部？是否绝对没有遮挡任何数据曲线或散点？
[ ] 9. 【字符纯净】所有中文字符、希腊字母（α, β, ΔE）及负号是否渲染正常无乱码？
[ ] 10.【高光标注】是否在核心极值、拐点、分界线处配置了引线说明（In-situ Annotations）？
[ ] 11.【版心比例】在 A4 页面（0.85\textwidth 约 15cm）缩放下，图内文字是否依然清晰、字号是否协调？
[ ] 12.【双轨保存】图表是否已按 300+ DPI 保存至 paper/figures/ 并同步至 paper/latex/figures/？
```

---

## 二、评分判定与闭环整改机制

- **优秀（90 ~ 100 分）**：12 项全过，图面层次分明，具备 Nature/Science 子刊级视觉冲击力，直接放行；
- **及格（75 ~ 89 分）**：存在微小瑕疵（如引线框位置略拥挤、边距有微小富余），但无科学误导，允许轻量调整后放行；
- **不合格（< 75 分，必须熔断重绘）**：
  - 触发任何一项硬伤（如：中文方块乱码、无断轴截断、图例遮盖峰值数据点、色板私自使用彩虹色 `jet`）；
  - 触发熔断时，必须自动重新运行绘图脚本修复，直至 Visual QA 达到 90 分以上。
