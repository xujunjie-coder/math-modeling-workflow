# 完整参赛论文目录契约

仅在 `paper_scope=full_submission` 时读取。用户提供的当届竞赛目录或明确要求优先；否则使用下列语义角色，不强行保留示例题目措辞。

```text
论文标题
摘  要
关键词

一、问题重述
二、问题分析
    2.1 问题一的分析
    2.2 问题二的分析
    ...
    2.n 各问逻辑关系（确有依赖时）
三、数据预处理
四、模型假设与约定
五、符号说明与名词定义
六、模型的建立与求解
    6.1 问题一：目标或方法
        6.1.1 方法/数据对象
        6.1.2 模型建立与求解
        6.1.3 结果与分析
        6.1.4 本问小结
    6.2 问题二：目标或方法
    ...
七、模型检验与误差分析

    8.1 模型优点
    8.2 模型不足与推广
    8.3 主要结论

```

## Placement Rules

- “问题重述”和“问题分析”是全局章节，只出现一次。
- 第三至第五章承载所有问题共享的数据口径、假设和符号；局部例外在对应 `6.x` 定义。第四章在有明确约定事项时标题为“四、模型假设与约定”，无额外约定时动态调整为“四、模型假设”；假设条目统一以“假设……”句式模板陈述。
- 每个顶层问题占一个 `6.x`。问题内部的小问使用 `6.x.y`，不能重新使用中文一级标题。
- 结果随对应模型出现；跨问题共用的稳健性与误差证据可集中到第七章，并在 `6.x` 给出明确指针。
- 第八章评价整个解题系统，不复制各问小结。
- 摘要和 `8.3` 在正文装配完成后撰写，逐问回应且使用冻结数字。
