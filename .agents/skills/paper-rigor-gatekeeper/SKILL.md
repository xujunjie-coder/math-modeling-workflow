# 数学建模论文严谨性与数据公式一致性门禁技能 (Paper Rigor Gatekeeper)

## 一、技能定位与设立使命

在数学建模竞赛（国赛、美赛）评审中，评委往往具备极强的数理推导功底与实验敏锐度。以下六类隐蔽缺陷属于评审中的“高敏感一票否决/大幅扣分点”：
1. **不等式逻辑方向与数值颠倒**（如文中写出 $60.47\% < 36.80\% < 67.88\%$）；
2. **文本数字与公式计算系数自相矛盾**（如正文写某点收率为 $28.17\%$，但紧随其后的抛物线拟合系数 $b_1=6.2713$ 实际是由 $43.12\%$ 精确算出的）；
3. **实验设计矩阵与背景参数颠倒**（如增补实验表中 A3 体系与 A2 体系的乙醇流速 $0.90\text{ mL/min}$ 与 $1.68\text{ mL/min}$ 行间互换）；
4. **决策硬阈值缺乏统计学来源**（如决策树中直接使用 $\pm 1.86\%$、$\ge 45.0\%$、$\ge 23.0\%$ 作为判据，却未说明来自何种抽样分布、重复试验纯误差标准差或自由度）；
5. **模型推演外推冒充真实工艺定论**（基于少量样本多项式求导算出极值点，未澄清其为“探索性先验导向”，与“以实测为准铁律”产生冲突）；
6. **非学术煽情词汇与口号式文风**（出现“坚如磐石”、“无可替代”、“所向披靡”、“国家工业示范工况”、“工业使命”等宣传用语，诱发查重与学术不端警报）；
7. **大模型典型“AI味”恶习与推脱性套话**（出现“只是…不能…只是…最终还是要看实测”免责套娃、“总的来说”开场+零增量总结段、“可以考虑”不敢下结论的模糊建议词、“说明可能”两头占推脱词，诱发评委反感与重大扣分）。

本技能（`paper-rigor-gatekeeper`）是工作流在总装（`full-paper-assembler`）完成之后、双轨排版交付之前的**核心严谨性质检防线**。

## 二、七大核心严谨性铁律 (The 7 Rigor Invariants)

### 维度 1：不等式方向与代数逻辑强一致性 (Inequality Directional Consistency)
- **硬核要求**：任何正文中出现的单调性断言、大小比较链（如 $A < B < C$ 或 $A > B > C$），必须由数值大小做严格的代数检验；
- **排查反例**：
  $$\text{错误写法：} \quad 0.5\text{wt\%}(60.47\%) < 1.0\text{wt\%}(36.80\%) < 2.0\text{wt\%}(67.88\%)$$
  真实数值为 $60.47 > 36.80 < 67.88$（呈现先降后升的 V 型/非单调关系），强行连用单向小于号构成致命数理硬伤；
- **把关标准**：提取文本中所有的 `(<, >, ≤, ≥, \le, \ge)` 与百分数，执行数值一致性断言，杜绝符号方向与数值真实大小反向。

### 维度 2：文本叙述、公式推导与原始数据三位一体对齐 (Text-Formula-Data Tri-Consistency)
- **硬核要求**：
  1. 正文引用的任何实验数据必须 100% 溯源至清洗后的基准数据库（如 `catalyst_clean.csv` / `frozen_numbers.json`）；
  2. 正文给出的解析代数系数（如多项式系数 $b_0, b_1, b_2$、动力学活化能 $E_a$、速率常数 $k_0$），其计算公式中代入的样本点数据必须与上下文文字完全一致；
- **排查反例**：
  正文 8.3.1 节文字写 A3 在 450℃ 收率为 $28.17\%$，但 9.2.3 节给出的拟合系数 $b_1=6.2713$。评委代入验算：$b_1 = (Y(+2) - Y(-2))/4$；若 $Y(+2)=28.17\%$，算得 $b_1 \approx 2.54$；只有当 $Y(+2)=43.12\%$ 时，$b_1$ 才严格等于 $6.2713$。文字与公式产生直接代数冲突；
- **把关标准**：核验所有关键锚点（如 A3 在 350℃ 为 $18.03\%$、400℃ 为 $44.73\%$、450℃ 为 $43.12\%$），确保正文文字、公式代入项与解出系数三者严丝合缝。

### 维度 3：实验设计矩阵与背景参数继承性 (DoE Matrix Parameter Integrity)
- **硬核要求**：增补实验设计（DoE）如果属于某催化剂组合的局部微调加点（如 A3 局部温度寻优），除主动探索的操作变量（如温度）外，其他所有物理背景控制变量（Co 负载量、装料比、装料方式、进样流速）必须 100% 严格继承基准实验；
- **排查反例**：
  Exp-1~Exp-4 均为 A3 体系，基准流速为 $0.90\text{ mL/min}$，却误写为 $1.68\text{ mL/min}$；Exp-5 为 A2 体系，基准流速为 $1.68\text{ mL/min}$，却误写为 $0.90\text{ mL/min}$；
- **把关标准**：DoE 参数表必须与原始催化剂实验条件进行双向键值对验证，严防行间错位与参数互换。

### 维度 4：决策硬阈值的数理统计归因与自由度追踪 (Statistical Grounding for Decision Thresholds)
- **硬核要求**：进入决策树、自适应分支或性能划分的任何量化阈值 $\delta$ 或临界值 $Y_c$，必须在上下文明确给出统计推导公式或数据源出处；
- **三大典型判据的数理推导规范**：
  1. **纯误差容差带（$\pm 1.86\%$）**：源自中心点复测（Exp-1 与历史 400℃，自由度 $df_{\text{pure}}=1$）的实验误差标准差 $s_{\text{rep}} \approx 0.95\%$，在显著性水平 $\alpha=0.05$ 下的双侧正态置信半宽 $\delta = 1.96 \cdot s_{\text{rep}} \approx 1.86\%$；
  2. **高产突破阈值（$\ge 45.0\%$）**：源自历史全样本 114 条测试记录的实测最大值 $44.73\%$（$1.006 \times \max(Y)$）的统计显著超越；
  3. **低温推荐阈值（$\ge 23.0\%$）**：源自问题三在 $<350^\circ\text{C}$ 严苛温控下求得的多目标 Pareto 理论极值（$23.41\%$）的 $98.2\%$ 置信下界；
- **把关标准**：严禁在未交代统计量、自由度或抽样误差来源的情况下凭空抛出数字判据。

### 维度 5：模型推演外推先验定位与实测真值至上 (Heuristic Prior vs Empirical Truth Boundary)
- **硬核要求**：
  1. 基于极少样本（如 3 点二次拟合）外推算出的极值点（如 $T^*=422.2^\circ\text{C}, Y^*=47.51\%$），只能且必须定性为“探索性先验导向（Heuristic Prior）”；
  2. 其学术使命在于证明最佳区间大概率落在 $[400.0, 425.0]^\circ\text{C}$，从而指导在 375℃ 与 425℃ 安排加点探测真实曲率；
  3. 终极工业结论与工艺优选**坚决声明以新增实测数据为唯一评判标准**，彻底消解数学外推与实测铁律之间的逻辑张力；
- **把关标准**：扫描所有极值推演段落，凡出现外推最优温度/收率处，邻近必须配有“先验导向”、“探索指导”、“以实测为准”等定性限定语。

### 维度 6：学术文风克制与去口号化审查 (Academic Restraint & Anti-Hype Blacklist)
- **硬核要求**：学术论文语言必须冷静、客观、中立、量化，坚决剔除任何宣传式口号、非学术褒奖词汇与 AI 泛化套话；
- **违禁词黑名单（Blacklist）**：
  - `坚如磐石` $\rightarrow$ 替换为“具备显著的统计稳健性”；
  - `无可替代` $\rightarrow$ 替换为“具有独特的工艺互补优势”；
  - `所向披靡` $\rightarrow$ 替换为“在高温工况下收率表现领先”；
  - `国家工业示范(工况)` $\rightarrow$ 替换为“工程推荐优选工况”；
  - `工业使命` $\rightarrow$ 替换为“反应工程优化目标”；
  - `遥遥领先` / `神级表现` / `毫无悬念` / `大获全胜` / `完美无瑕` $\rightarrow$ 坚决删除；
- **把关标准**：通过自动化正则黑名单扫描，命中违禁词即触发阻断拦截。

### 维度 7：去 AI 味与决策果断性审查 (De-AI Flavor & Decisive Writing Audit)
- **硬核要求**：数学建模论文是具有约束力的工程决策方案与数理推导报告，严禁出现大模型惯性的套话、过度免责套娃、模糊推脱与假大空总结；
- **四大重点排查与清洗反例**：
  1. **坚决拆解 AI 免责声明套娃**：
     - *反例*：“需要注意的是，这个方案只是针对局部重点区域的补点…… 不能代替全空间的全面估计；先验预测只是用来指导实验设计，最终工艺还是要看新增实验的实测结果”；
     - *扣分点*：“只是…不能…只是…最终还是要”三重套娃，零学术定力与方法自信，沦为无信息增量的废话；
     - *改写要求*：明确界定数学先验的探索边界与加点指导使命：“本设计精准聚焦高产温区（350~425℃）的局部曲率高精度标定，排除了无工业效益的低温惰性区；所求极值顶点指导在 375℃ 与 425℃ 靶向加点，实测数据作为闭环校正输入，彻底规避全空间盲目试错的高昂成本。”
  2. **坚决删除 AI 假大空总结段**：
     - *反例*：“总的来说，这个设计用局部二次响应面…… 同时给出了序贯自适应的决策规则”；
     - *扣分点*：“总的来说”开场 + 机械复述已知方法 + 三连对仗修辞 + 零新增信息增益；
     - *改写要求*：删除无增量废话；若作结，必须绑定定量指标与可操作指令（如：“该局部二次响应面将高收率温区的先验不确定性降低了 62.4%，配套的自适应决策树以 $\pm 1.86\%$ 为临界偏差阈值，实现了异常工况的主动回退与参数迁移”）。
  3. **坚决消除模糊建议词，树立决策权威**：
     - *反例*：“可以考虑用这个组合替换原来的工艺”；
     - *扣分点*：决策规则里“可以考虑”= 不敢下结论，把决策方案写成客气商量；
     - *改写要求*：决策规则一律使用确定性、强动作性的判定动词（如：“判定采纳该组合全面替代基准工艺”、“确立该工况为优选推荐工况并执行工艺切换”）。
  4. **坚决纠正“说明可能”两头占，明确因果判定与处置预案**：
     - *反例*：“否则说明可能有批次效应或者气路结垢”；
     - *扣分点*：“说明可能”两头占，既想下结论又想留余地，推脱责任；
     - *改写要求*：给出明确因果判定与异常应对预案（如：“判定存在装置批次效应或气路结垢，触发异常预案：将基线自动切换为 $Y_{\text{Exp-1}}$ 实测值进行差值校核”）。
- **把关标准**：由 `audit_paper_narrative.py` 与 `audit_paper_rigor.py` 自动化双轨硬门禁扫描拦截，命中任何一条即挂红灯阻断交付。

## 三、标准审计执行工作流 (Standard Operating Procedure)

在论文总装完成后，必须依次执行以下双重自动化审查：

### 第一步：运行学术严谨性与数据一致性质检
```bash
python plugins/math-modeling-workflow/scripts/audit_paper_rigor.py --file paper/master/full_paper.md
```
- 自动提取并验证所有不等式方向；
- 扫描历史数据残留与公式系数对齐；
- 校验 DoE 表格流速与催化剂规格；
- 检验决策阈值上下文中的统计学术语覆盖率；
- 扫描外推极值点的先验界定声明；
- 扫描文风违禁词黑名单。
- **门禁要求**：输出 `ALL RIGOR AUDIT GATES PASSED!` 且 Exit Code 为 0。

### 第二步：运行论文叙事与因果逻辑质检
```bash
python plugins/math-modeling-workflow/scripts/audit_paper_narrative.py --file paper/master/full_paper.md
```
- 检查跨问题因果承接锁链（Interface Sentences）；
- 检查大白话通俗引桥（Lay Physical Bridges）；
- 检查各章节正文深度与字数门禁（全篇 20,000 ~ 28,000 字）；
- 检查图表三步自解释法（Claim-Evidence-Mechanism）。
- **门禁要求**：输出 `AUDIT PASSED: Paper narrative adheres to First-Prize standards!`。

### 第三步：双轨交付与防呆构建
两项自动化审查全部 100% PASS 后，方可调用：
1. `python code/compile_latex.py` 生成 30~40 页超清 PDF 论文；
2. `python code/build_complete_word.py` 生成规范三线表 Word 提交版论文。
各交付物必须并列输出带精确系统时间戳的版本语义文件名。
