# 论文撰写语言风格与专业名词处理规则

本规则适用于在当前数学建模工作流中撰写、组装、润色所有论文段落与最终全文（包括 Markdown、Word 与全文装配）的 Agent 与技能。

## 核心七大原则

### 1. 专业名词必须突出显示（加粗）
- **格式要求**：在撰写论文的 Markdown 源码中，凡涉及统计学方法、优化算法、专业机理、实验指标及特定领域术语，必须统一使用加粗进行突出显示，形如 `**专业名词**`。
- **设计初衷**：为人工复查提供清晰的视觉锚点，使参赛队员在阅读时能够一眼发现专业术语，并便于根据队伍实际风格，自行将其润色修改为通俗、接地的口语化表达。
- **常见突出显示术语示例**：
  - 算法与方法：`**主成分分析 (PCA)**`、`**中心对数比变换 (CLR)**`、`**双向逐步回归**`、`**TOPSIS 综合评价法**`、`**随机森林**`、`**非退化解**`
  - 统计与检验：`**多重共线性**`、`**方差膨胀因子 (VIF)**`、`**Benjamini-Hochberg (BH) 校正**`、`**置信区间**`、`**显著性水平**`
  - 领域概念：`**风化机理**`、`**铅钡硅酸盐**`、`**成分流失**`、`**富集效应**`

### 2. 严禁自创简短生硬短语
- 坚决杜绝大模型常见的“生搬硬凑四字词”、“生硬缩写”或脱离中文语境的合成短语（例如禁止自造如“铅钡风度”、“聚类度差”、“残偏比”、“模解比”等莫名其妙的简短短语）。
- **处理原则**：
  - 若属于公认学术规范词，请使用规范完整名称；
  - 若为特定过程、复合指标或现象，**必须使用完整、流畅的句子展开阐明其内涵**，严禁擅自造词。

### 3. 必要时允许并鼓励口语化表述
- **反对过度堆砌晦涩学术八股**：在确保数学推导和逻辑严谨的前提下，特别是在**建模背景引入、公式背后的直观几何/物理意义、约束条件的现实含义，以及最终结果的应用解读**时，**允许并鼓励使用通俗、自然、接地气的口语化中文**。
- **好表述对比**：
  - *晦涩八股*：“鉴于各变量之间存在显著之共线趋向，遂实施正交化降维投射……”
  - *通俗口语化（推荐）*：“通俗来说，由于这些化学成分之间相互关联紧密（存在明显的信息重叠），我们通过降维把重复的信息提炼出来，抓主要矛盾……”
  - *晦涩八股*：“该非负约束条件旨在规避决策空间向负值域之非常规漂移……”
  - *通俗口语化（推荐）*：“从现实常识来看，材料的投放量或配比不可能为负数，因此我们加上了非负约束，防止出现违反常理的结果……”

### 4. 严禁机械使用“小问”称谓，无明示时省略主语自然承接
- **严格区分内部工程解题与论文对外呈现**：
  - 虽然解题流程内部常把一个大题拆解为若干执行单元（如 subproblem_1, subproblem_2），但**若题目原文未正式划分子小问，论文正文与标题严禁写出“第一问的第一小问”、“对于第一小问”、“针对第二小问”等机械表述**。
- **处理方式**：
  - **直接省略主语**：跳过结构代词，直接承接具体任务。例如写成：“首先对原始数据进行清洗与异常值检验……”、“进而建立多元非线性回归模型……”，而不是“针对第一小问，首先……”。
  - **以研究任务/对象命名小标题**：小节标题采用具体的方法或业务目标命名（如 `4.1 玻璃文物的分类规律挖掘`、`4.2 化学成分关联分析`），严禁使用 `4.1 第一小问模型` 这种生硬命名。
  - **原题有明确 (1)(2) 小问时**：直接顺应原题设问，亦避免混淆层级或多重嵌套（如不写“第一题第一问”，简明写“针对第 (1) 问”或直接顺畅推进）。

### 5. 模型假设与约定：动态标题判定与“假设……”模板
- **章节标题动态命名**：
  - 论文中模型假设部分**必须具备假设**；
  - 若确有符号、常数或计算口径的额外约定事项，章节标题使用“**模型假设与约定**”；
  - **若没有约定事项，章节标题必须精简为“模型假设”**，严禁挂空“与约定”字样。
- **统一假设句式模板**：
  - 每一条假设的表述必须统一采用以“**假设……**”开头的标准句式模板：
    - 示例：`假设1：假设采样检测数据真实可靠，未受取样过程中的二次化学污染；`
    - 示例：`假设2：假设文物的风化过程主要受埋藏环境影响，且同坑位埋藏条件具有同质性；`
    - 句式规则：`假设X：假设[明确前提条件/系统行为]，从而[保证模型成立的逻辑]。`

### 6. 论文作图后必须紧跟深度论述，围绕图片得出结论
- **严禁“放图不评”或“蜻蜓点水”**：
  - 严禁正文中仅出现“如图X所示”就直接跳至最终数值，严禁只在图注写一句话而在正文缺乏实质分析。
- **强制围绕图片展开深入论述**：
  - 论文在嵌入图片后，正文紧接着必须围绕该图片展开 1~2 段具有分析深度的论述；
  - **固定引导句式**：必须明确包含如“**通过上述图X可以得出……**”、“**由图X可以看出，……**”、“**结合上述图片反映的分布/变化规律，可以发现……**”等论述句式；
  - **论述三步走**：
    1. **描述视觉规律**：走势、拐点、波峰波谷、群组分界、离群点等；
    2. **解释现实/机理成因**：为什么图里会呈现这种规律；
    3. **提炼建模支撑结论**：该图为后续哪一步模型构建、特征筛选或参数估计提供了决定性支撑。

### 7. 表格与图片标号：两阶段生命周期管理
- **阶段一（小问起草与整合初期：分章节编号）**：
  - 在各个小问独立撰写、分析计算以及总论文初步合并阶段，表格和图片**统一先按照章节进行编号**；
  - 格式：`图X-Y`、`表X-Y`（X为章节号/问题号，Y为该章内部递增顺序号）；
  - 示例：第一章节为 `图1-1`、`图1-2`，`表1-1`、`表1-2`；第二章节为 `图2-1`、`表2-1`；
  - 作用：各小问独立撰写与增删调整时互不干扰，便于局部调试与审查。
- **阶段二（全文人工总体审核阶段：保留章节编号）**：
  - 汇总合并为 `paper/master/full_paper.md` 后，先保留原分章节编号，供参赛团队人工总体通读、审核与修改，方便逐题对照证据溯源。
- **阶段三（人工审核确认无误后的最终定稿：全局连续重编号）**：
  - **触发条件**：团队人工审核完成、修改确认无误后；
  - **全量重编号**：将全篇所有图片与表格按在全文正文首次出现的顺序，统一转换为全局自然递增顺序编号：
    - 图片：`图1`、`图2`、`图3`、`图4`、`图5`……
    - 表格：`表1`、`表2`、`表3`、`表4`、`表5`……
  - **正文交叉引用全量同步替换**：
    - 正文中的所有文字引用必须全量映射替换（例如将“通过上述图1-1可以得出……”自动同步替换为“通过上述图1可以得出……”；“参见表2-1”替换为“参见表3”等），严禁残留旧的分章节编号。
  - **全自动脚本一键执行**：
    - 严禁耗费大量人工去手动搜索替换。直接运行自动化脚本：`python plugins/math-modeling-workflow/scripts/renumber_figures_tables.py paper/master/full_paper.md --in-place`，即可全自动完成图表全局连续重编号及全篇正文引用的无缝同步映射。
