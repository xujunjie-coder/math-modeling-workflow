# 全国大学生数学建模竞赛论文标准结构规约 (National Contest Paper Structure)

本规范依据全国大学生数学建模竞赛官方格式与提供的标准模板（`plugins/math-modeling-workflow/assets/templates/national_contest_template.docx` / `国赛模板 (1).docx`）制定。
AI 在生成论文正文与最终组装时，必须严格执行该标准章节体系与内容要求。

---

## 一、标准十二大核心板块结构

```
标题 (Title)
摘  要 (Abstract)
  - 核心背景与论文概括 (3~5行)
  - 问题一求解与核心结果 (含方法/模型/关键数值)
  - 问题二求解与核心结果 (含方法/模型/关键数值)
  - 问题三求解与核心结果 (含方法/模型/关键数值)
  - 结尾总结与模型推广亮点 (1~2句)
  - 关键词：关键词1  关键词2  关键词3  关键词4 (4~6个，空格分隔)

一、问题重述 (Problem Restatement)
  - 1.1 问题背景 (整理原问题背景)
  - 1.2 问题提出与重述 (分开陈述，严禁照抄原题文本)

二、问题分析 (Problem Analysis)
  - 包含题目给出条件与已知信息提炼
  - 总体建模逻辑与各问题求解思路分析，简明扼要，不放最终数值结论

三、模型假设与约定 (Model Assumptions and Conventions)
  - 统一使用“假设……”或“约定……”句式

四、符号说明 (Symbol Description)
  - 必须采用标准三线表（符号 | 说明 | 单位）

五、数据预处理 (Data Preprocessing)
  - 缺失值、异常值处理、量纲归一化、特征工程分析

六、问题一模型的建立与求解 (Model 1: Formulation and Solution)
  - 6.1 基于[方法]的[目的]模型建立
  - 6.2 模型求解与结果分析 (含插图三步法分析、表格、数值解释)

七、问题二模型的建立与求解 (Model 2: Formulation and Solution)
  - 7.1 基于[方法]的[目的]模型建立
  - 7.2 模型求解与结果分析

八、问题三模型的建立与求解 (Model 3: Formulation and Solution)
  - 8.1 基于[方法]的[目的]模型建立
  - 8.2 模型求解与结果分析

九、模型的评价、改进与推广 (Evaluation, Improvement and Extension)
  - 9.1 模型的优点
  - 9.2 模型的不足与改进策略
  - 9.3 模型的实际推广与应用前景

十、AI工具使用声明 (AI Tools Usage Declaration)
  - 竞赛官方要求声明：
    “本参赛队在竞赛过程中使用了AI工具，主要用于语言润色、代码调试与格式排版，详细使用情况与提示词记录见支撑材料。”

十一、参考文献 (References)
  - 遵循 GB/T 7714-2015 格式，严格 1-to-1 正文上标对应 `[^1]`
  - 真实权威无虚构，包含文献类型标识 `[M], [J], [S], [C], [D], [EB/OL]`

十二、附录 (Appendices)
  - 附录A 支撑材料文件列表 (规范表格：序号 | 所属问题 | 文件名称 | 功能说明)
  - 附录B 补充图表 (敏感性分析长图、高维数据补充表格)
  - 附录C 核心代码清单 (带清晰注释的标准求解代码)
```

## 二、各部分写作细则与禁忌

### 1. 摘要段落规范（评卷核心）
- **第一段（概括段）**：两到三句话即可，总长度控制在 3 到 5 行，点明研究背景与解决的总体任务。
- **问题段落**：每个子问题单独成段，采用模板化句式：
  *“针对问题一，针对……难点，应用了……方法，建立了……模型；经……算法求解，得到……（必须包含核心定性与定量结论、具体数值）；结果表明……”*
- **末段（总结亮点）**：总结全文模型优势，说明鲁棒性或创新点，并简述向现实场景的推广价值。
- **关键词**：4 到 6 个，选取关键算法、问题核心对象、重要数学模型，以空格或分号清晰分隔。

### 2. 问题重述规范
- **禁止照抄原题**：查重系统重点比对题目，必须用自己的学术语言重新提炼问题背景、约束条件与目标任务。

### 3. 符号说明表规范
- 必须使用标准**三线表**（Top line 粗, Mid line 细, Bottom line 粗）。
- 每一行包含：数学符号（LaTeX 格式）、物理/数学说明、标准量纲或单位（无量纲须注“无量纲”或“/”）。

### 4. AI 工具使用声明规范
- 必须包含在正文末尾、参考文献之前。
- 声明必须客观真实，符合全国组委会对于辅助性工具的学术诚信指引。

### 5. 附录 A 支撑材料文件列表
- 必须与实际提交的压缩包/支撑材料文件夹保持完全一致：
  | 序号 | 对应问题 | 文件名 | 格式 | 说明 |
  | :---: | :---: | :---: | :---: | :---: |
  | 1 | 数据预处理 | `data_clean.py` | Python 脚本 | 原始数据清洗与标准化 |
  | 2 | 问题一 | `q1_solve.py` | Python 脚本 | 问题一模型建立与求解 |
  | 3 | 结果数据 | `result_q1.xlsx` | Excel 表格 | 问题一最终计算输出结果 |

### 6. Word 与 LaTeX 双轨渲染与数学符号防瑕疵规约
为了保证最终提交成果在不同评阅环境下的极致视觉效果，AI 必须生成两套互补的排版成果：
1. **Word 版本 (`final_paper.docx`)**：
   - **严格去代码化**：正文与表格中绝对严禁遗留 `$`、`\chi`、`\pm`、`_` 等原始 LaTeX 标记；
   - **符号标准化**：将行内公式自动转换为 Unicode 符号与规范上下标（如 $\chi^2 = 5.4518$、$p = 0.0195$、$V = 0.3066$）；
   - **化学式规范**：所有涉及的化学物质自动转为规范下标格式（如 $\text{SiO}_2$、$\text{K}_2\text{O}$、$\text{Al}_2\text{O}_3$、$\text{PbO}$）；
   - **表格三线表**：顶线与底线加粗，标头栏下细线，单元格内容居中/左对齐。
2. **LaTeX 版本 (`paper/latex/paper.tex` ➔ `final_paper_latex.pdf`)**：
   - **原生编译引擎**：基于 XeLaTeX + ctexart 原生编译，自适应 Windows 系统中文字体；
   - **学术级数学排版**：包含 AMS-LaTeX 原生公式环境、分段函数、矩阵运算及 `booktabs` 专业三线表；
   - **表格宽度与防止溢出规约（关键）**：
     - 导言区必须引入 `\usepackage{tabularx}`、`\usepackage{booktabs}` 与 `\usepackage{graphicx}`；
     - **严禁使用单行不换行的固定列 `l/c/r` 排版长文本列**（如说明、含义、长变量名等），避免表格右侧冲出页边距或被页面截断；
     - 凡包含长文本说明的三线表（如符号说明表、附录支撑材料清单表），必须使用 `\begin{tabularx}{\textwidth}{...}`，并将文本说明列设为自适应 `X` 列（或 `p{宽度}`），使长文本在版心内自动换行并对齐右边缘；
     - 超宽综合对比数据表必须使用 `\resizebox{\textwidth}{!}{...}` 进行弹性包裹缩放，确保 100% 严丝合缝贴合版心宽度 `\textwidth`；
   - **完全自包含**：所有插图本地引用 `paper/latex/figures/`，源码可直接打包迁移至 Overleaf 或任意 TeX 发行版。
