# 数学建模竞赛实战操作指引（拿到题目和附件后如何使用）

本指南专为全国大学生数学建模竞赛实战设计。遵循“**AI 全自动无人值守（Auto-Pilot）推进，人类仅负责终审**”的设计目标，帮助参赛队在拿到题目和附件后以最快速度启动并高质量完赛。

---

## ⚡ 极简三步实战流程

```text
【第一步：放文件】
将题目放到 problem_statement/，将数据附件放到 data_raw/
          ↓
【第二步：唤起 AI】
在对话框输入一条启动指令（支持直接复制模板）
          ↓
【第三步：人类终审】
AI 全自动完成建模、代码、绘图与论文后，人类通读审核并提交！
```

---

## 一、第一步：存放赛题与附件数据

在当前工作区根目录下，将题目文件与数据附件按以下规则归档：

1. **赛题文件存放位置**：
   - 路径：`problem_statement/`
   - 支持格式：PDF、Word (`.docx`) 或文本/Markdown (`.txt`, `.md`)。
   - 建议命名：`problem.pdf` 或 `赛题说明.docx`（如有多道题选择，只放所选赛题）。

2. **数据附件存放位置**：
   - 路径：`data_raw/`
   - 支持格式：Excel (`.xlsx`, `.xls`)、CSV (`.csv`)、文本数据等。
   - 命名建议：保持原文件名即可（如 `附件1.xlsx`、`附件2.csv`）。
   - **铁律**：`data_raw/` 中的原始数据永远只读，AI 绝不会篡改原始附件。

> 💡 **提示**：如果是一个全新的比赛文件夹，可在终端运行一条初始化命令生成目录骨架：
> ```bash
> python plugins/math-modeling-workflow/scripts/init_workspace.py .
> ```
> （当前工作区已预置好完整目录，可直接放入文件）。

---

## 二、第二步：唤起 AI 端到端自动推进

文件放入后，无需在后台手动敲打复杂命令，**只需在当前 IDE 对话框中发送如下指令**：

### 🎯 推荐启动指令（直接复制发送）

> “**我已经将赛题放入 `problem_statement/`，数据附件放入 `data_raw/`。请启动 Auto-Pilot 模式，端到端完成题目解析、数据清洗、各问题选型求解、统一科研配色绘图、论文撰写，并严格按照国赛标准模板生成最终提交论文。**”

---

## 三、第三步：AI 在后台全自动执行的工作流（参赛队无需分心）

发送指令后，AI 将自动调用各专业技能（Skill），流水线式推进全流程。人类队员可去讨论其他思路、休息或关注官方通知，中间阶段**无需人类思考与干预**：

| 阶段 | 对应门禁 | AI 自动执行的任务 | 严格遵循的规则 |
| :--- | :--- | :--- | :--- |
| **1. 审题与清洗** | G1 | 自动解析背景，拆解小问依赖，完成数据清洗与标准化，输出数据画像 | 原始数据零篡改，清洗规则透明记录 |
| **2. 背景调研与方法选型** | G2 / G2.5 | 联网检索专业背景常数与行业机理，确定各问题主方法与基线模型 | **奥卡姆剃刀原则（简单模型优先）**，高可解释性 |
| **3. 代码编写与运行** | G3 | 编写 Python / MATLAB 求解代码并实际运行，输出数值结果与表格 | **命名法则**：化学式（`Pb`, `SiO2`）+ 四级英文 + 拼音（`fenghua`），文件名极简 |
| **4. 统一科研绘图** | G3 / G4 | 依据计算结果自动绘制所有热力图、相关性图、折线对比图、柱状图 | **统一科研配色**：红蓝双极发散（`#053061`至`#6A0624`），离散学术6色，灰度基线 |
| **5. 结果验收与数据冻结** | G4 | 自动检验数值收敛性与合理性，自动完成数字签名冻结 (`frozen_numbers.json`) | 确保论文中的每一个数字都能追溯到代码真实输出 |
| **6. 论文章节撰写** | G5 | 撰写各问题论文草稿，图表采用分章节编号（`图1-1`, `表1-1`） | **文字风格**：核心专业术语加粗、图后三步法深入论述、自然任务过渡 |
| **7. 论文总装与全局重排** | G5.5 | 合并为完整 master 论文，调用 `renumber_figures_tables.py` 脚本自动全局重编号（`图1`, `图2...`）并同步修改正文引用 | **参考文献**：100% 真实权威（经典教材/核心文献），GB/T 7714-2015，与正文严格 1-to-1 对应 |
| **8. 格式化排版与渲染** | G5.6 | 依托官方国赛模板 (`national_contest_template.docx`) 输出最终成果 | **标准十二大板块**：含摘要五段式、问题重述、三线表符号说明、AI使用声明、附录A支撑材料清单等 |

---

## 四、第四步：人类终审与提交（比赛交卷前）

当 AI 运行完成并提示论文生成完毕后，参赛队进入**最终版本审核阶段**：

### 1. 成果文件位置
- **最终提交论文 Word 版**：`paper/final/final_paper.docx`
- **最终提交论文 PDF 版**：`paper/final/final_paper.pdf`
- **全篇排版源 Markdown**：`paper/master/full_paper.md`
- **所有高质量矢量/高清插图**：`paper/figures/`
- **支撑材料代码与数据**：`deliverables/` 或 `code/` 与 `results/`

### 2. 人类通读审核清单（耗时仅需 20~30 分钟）
1. **摘要核验**：
   - 检查摘要字数是否适合（通常一页内）；
   - 核对每个小问是否给出了明确的定量数字结论。
2. **术语与表述微调**：
   - 论文中加粗的 `**专业词汇**`，队员可根据现场语境做通俗化微调。
3. **图表与公式核验**：
   - 确认图表编号为连续顺序号（`图1`, `图2`, `图3...`），图题完整；
   - 确认热力图与曲线图配色协调美观。
4. **支撑材料打包**：
   - 核对 `附录A 支撑材料文件列表` 中的文件名与实际附件包一致；
   - 按照赛委会要求将论文与支撑材料打 zip 压缩包提交。
