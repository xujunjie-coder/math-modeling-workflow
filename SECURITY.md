# Security Policy

## Supported versions

Security fixes are applied to the latest released minor version.

## Reporting

Do not open a public issue for credentials, private contest data, path traversal, unsafe file deletion, or command-injection findings. Use GitHub's private vulnerability reporting feature when it is enabled on the repository.

The plugin is designed for local workspaces. Review generated code before running it, keep raw data read-only, and never commit secrets or private competition materials.
